# Plant Disease Detection Project

This project uses Machine Learning to detect plant diseases from leaf images.

## Files
- plantproject.ipynb : Jupyter Notebook containing the model training and prediction code.
- leaf_model.pkl : Trained machine learning model.
- test_leaf.png : Sample test image.
- images01.png to images05.png : Project output/screenshots.

## Features
- Leaf image analysis
- Disease prediction
- Machine Learning based classification

## Technologies Used
- Python
- Jupyter Notebook
- Scikit-learn
- NumPy
- Pandas
